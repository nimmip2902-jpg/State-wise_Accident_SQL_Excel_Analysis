# State-Wise Accident Analysis
# Project Overview
This project analyzes accident data across Indian states to identify patterns and trends in Road Accidents, Railway Accidents, and Railway Crossing Accidents.
The project uses MySQL for data analysis and SQL querying and Microsoft Excel for data visualization and dashboard development.
The objective is to transform raw accident data into meaningful business insights that can help understand accident concentration, injuries, deaths, and accident rates across different transport categories and states.

# Business Objective
The main objective of this project is to answer important business questions such as:
Which states have the highest number of road accidents?
Which states have the highest number of railway accidents?
Which states have the highest number of railway-crossing accidents?
Which states have the lowest accident counts?
Which states have the highest accident counts?
Which transport type contributes the most accident cases?
How many people were injured and killed in each accident category?
What are the injury and death rates per 100 accident cases?
How does the average number of accidents vary across transport types?
How does accident performance change when a particular state is selected?

# Key Insights
1. Road accidents have the highest volume

Road accidents account for the largest number of accident cases among the three categories, with 433,111 total cases.

2. Railway accidents have significantly fewer cases

Railway accidents account for 22,285 cases, considerably lower than road accidents.

3. Railway crossing accidents have the lowest case volume

Railway crossing accidents account for 2,557 cases.

4. Uttar Pradesh has the highest road accident count

Among the states displayed in the dashboard, Uttar Pradesh has the highest number of road accident cases.

5. Maharashtra leads the railway accident ranking

Maharashtra appears as the highest state in the railway accident analysis shown in the dashboard.

6. Uttar Pradesh leads railway-crossing accidents

Uttar Pradesh has the highest number of railway-crossing accident cases in the displayed ranking.

7. Accident levels vary significantly between states

The dashboard shows a considerable difference between states with the highest and lowest accident counts.
